# Sprint Goal - Sprint 11

Cilj zadnjeg sprinta je stabilizovati finalnu verziju sistema i pripremiti kompletnu završnu isporuku kroz provjerivu deployment proceduru, automatizovan i ponovljiv deployment putem CD pipeline-a, korisnički priručnik, završnu tehničku i procesnu dokumentaciju, ažuriran backlog, završni pregled testiranja i jasno evidentirana ograničenja sistema.

Projekat treba biti moguće pokrenuti, deployati, koristiti, testirati i evaluirati bez dodatnih neformalnih objašnjenja tima.
